## Manual — the `/demo` no-LLM / no-auth guarantee

The critical property. Verified with the **backend down** (nothing on `:8000`)
by loading `/demo` in headless Chrome and recording every network request:

| Build | `/demo` renders | Requests to `:8000` / `/portfolio/*` / `/overview` / `/analyze` |
| --- | --- | --- |
| flag-off | fully | **0** |
| flag-on | fully | **0** |

Grep confirms the demo route source contains no `fetch`, `streamOverview`,
`portfolioFetch`, or `API_BASE` use (only comments and import paths mention
`/portfolio`). `next build` marks `/demo` `○ (Static)` — prerendered, no runtime
data.

Contrast: `/lab` (which legitimately reads the IND Money link) **does** call
`/auth/status` + the wake ping — confirming `AuthProvider` is scoped to the
surfaces that need it, not global.
