# M1 — how to verify the portfolio model and connectors

Companion to [`docs/SPECS/M1.md`](../SPECS/M1.md). Everything below runs offline
except the live smoke test in §4.

```bash
source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
cd backend
pytest                      # 275 passed, 6 skipped without a Postgres
```

The 6 skips are F1's DB tests; they skip loudly, naming the URL they tried. No
Postgres, no network and no IND Money credential is needed for any M1 test.

## 1. The four test files, and what each one actually proves

### `tests/test_portfolio_models.py` — 39 tests

The rules the *types* enforce, so a future connector cannot opt out of them by
forgetting. Grouped by the C2 finding each defends:

| Group | Proves |
| --- | --- |
| Decimal coercion | `to_decimal(0.1) == Decimal("0.1")` (i.e. it goes through `str`, not binary float); `int` and `float` inputs for the same field land identically; bools and junk raise. |
| Cost basis | `invested_amount=0` is **rejected outright** by `Holding` and `AllocationSlice`; a `None` basis cannot carry a P&L; a *known* basis may carry a legitimate `0` return; `derive_pnl` refuses `None`/`0` and returns a real −100% for a worthless holding. |
| `as_of` | Naive datetimes raise; aware ones normalize to UTC. |
| Currency | Any non-INR value raises; all five models default to INR; US exposure is signalled by `asset_type` alone, including for the out-of-enum wallet bucket. |
| Asset types | `queryable()` is exactly the vendor's 16; six kinds of junk all coerce to `UNKNOWN` without raising; the original string survives. |
| Absences | No model has an `xirr` field; unknown fields are rejected; the enums match the documented vocabularies. |

The `stable_external_id` test is worth naming: it caught a real ambiguity bug —
the first implementation joined parts with a separator, so `("a|b",)` and
`("a","b")` hashed identically. It now JSON-encodes first.

### `tests/test_portfolio_ind_money_connector.py` — 54 tests

The vendor mapping, driven entirely off the **C2 synthetic fixtures** through an
injected transport (`tests/ind_money_transport.py`). No network, no credential.
Highlights:

- **Transport contract** — the connector consumes exactly what
  `tools.ind_money._unwrap` produces, proven by feeding it the committed
  `raw_mcp_envelope__*.json` through the real `_unwrap`.
- **Snapshot** — totals are passed through byte-for-byte (`Decimal(str(...))` of
  the payload value), the un-enumerable `US_STOCK_WALLET` bucket survives as
  `UNKNOWN` with its string intact and is recognised as US exposure, a missing
  total is a typed error, and an empty portfolio is not an error.
- **Holdings** — all six MF fixture rows map; the three unknown-cost-basis
  encodings (key absent, `0`, `null`) all yield `None` basis **and** `None` P&L;
  the zero-*value* row keeps its real −100%; the all-`int` row still yields
  `Decimal`; a cash-like row's `0` units/price become `None` rather than reading
  as a real price; empty asset types return `[]`; ids are unique and an empty
  instrument code falls back to a stable hash; empty display names become
  `None`; a `US_STOCK` row is flagged by asset type alone.
- **The UNVERIFIED `IND_STOCK` boundary** — the empty 19-key envelope maps to no
  rows; a documented-shape row maps; an **unexpected key** and a **missing
  value** each raise `UnverifiedShapeError`; and the same unexpected key on an
  `MF` row does **not** raise (forward-compatibility is deliberate everywhere
  except behind the unverified boundary).
- **Rate limiting** — a throttled response is retried after the server's own
  `retry_after_seconds` (recorded, not slept); the backoff is capped; both tiers
  raise `RateLimited` carrying `scope`/`window`/`limit`/`current`/`cost`; and a
  parametrized test proves a throttled body **never reaches the payload parser**
  on any of the four entry points. A non-rate-limit `error` body is a
  `SourceReportedError`; a missing key is a `PayloadShapeError`, never a
  `KeyError`.
- **Currency** — a doctored payload with `"currency": "USD"` raises
  `NonInrValue`; so does a nested one (and the error names the JSON path); an
  `"INR"` one passes. The doctoring happens **in the test**, deliberately not as
  a committed fixture: `test_ind_money_fixtures.py` asserts no committed fixture
  contains a currency key, and that assertion is correct and must stay.
- **Scoping and health** — every method refuses a `user_id` the connector is not
  bound to *before any network call*; all four `link_health` states are covered,
  including that a definitive rejection is `revoked` (and sticky) while a
  transient failure is only `needs_relink`.

### `tests/test_portfolio_connector_contract.py` — 43 tests

**One suite, parametrized over both connectors.** This is the file that makes
the seam real; a future source joins by adding one line to `CONNECTORS`.

It proves: both implement every abstract method, async, with `user_id` as the
first argument; both return typed, INR-denominated, UTC-stamped objects; both
have a non-empty portfolio with unique identities; both carry an
unknown-cost-basis row that yields `None` P&L; both handle an out-of-enum asset
type (either enumerating it *or* raising `UnsupportedAssetType` — never
crashing); both treat an empty allocation combination as a valid answer; and
both refuse an empty `user_id`.

One test is worth calling out: **`test_snapshot_totals_do_not_reconcile_with_
the_holdings_rows`** asserts the sum of holdings ≠ the snapshot's gross value,
on *both* connectors. That is not an accident of the fixtures — it is the
reconciliation gap made permanent in CI, so nobody can add an equality check
later without a test going red first.

### `tests/test_portfolio_boundary.py` — 28 tests

Greps `backend/portfolio/` (excluding `connectors/`) for every vendor field name
and tool name, checks that the model layer imports neither `tools.ind_money` nor
any connector, and — crucially — includes a **non-vacuity** test asserting those
same names *do* appear below the boundary. A grep test that could never fail is
worse than no test.

## 3. The leak gate

The repo is public and the demo fixtures are invented, so the C2 adversarial
check still applies to anything M1 adds under `docs/` or `backend/tests/`.

```bash
cd backend
python tests/leak_check_ind_money.py --captures <scratch-dir> --self-test
python tests/leak_check_ind_money.py --captures <scratch-dir>
```

`--self-test` plants a real capture value in a temp file outside the repo and
requires the scanner to catch it, so a PASS on the real files cannot be vacuous.
The scan itself needs a capture corpus, which C2 deleted after its gate — see
`docs/TESTING/C2.md` for how to re-capture into a scratch directory **outside**
the working tree, and delete it afterwards.

**Result on this branch (2026-08-15):** run against a fresh 3-call live capture,
`--self-test` PASS, then the real scan over 47 files initially **FAILED with 6
string overlaps** — four ordinary English words (`Equity`, `Discovery`,
`Industrials`, `Technology`) that invented fund and sector labels happened to
share with the operator's real payload. No amount, id or holding was involved.
The labels were renamed to C2's convention (`Demo Sector Alpha/Beta/…`) and the
gate re-run: **PASS**. Captures deleted immediately afterwards.

That is the gate working as intended, and it is why the demo fixtures avoid
plausible real-world sector names entirely.

## 4. Live smoke test

Optional, and the only thing here that touches the network. It proves the
connector maps a **real** payload, not just the fixtures.

Constraints, all of them deliberate:

- Run it from the **main checkout's** `backend/`, so the real `.env` and the
  real `backend/.ind_money_token.json` are the ones used, with the M1 worktree's
  `backend/` appended to `sys.path` so `portfolio.*` resolves to this branch.
- **Report only counts, types and conformance booleans. Never a value.** The
  repo is public; a portfolio total in a doc or a commit is the one failure this
  whole card is built to avoid.
- Pace it: 4 seconds between calls, 3 calls total. The per-tool limit is 15/min
  and the global one 30/min, so this is nowhere near either. Do **not** loop
  over all 16 asset types, and never sweep the 48-call allocation grid.

Sketch (the version used for this card lived in a scratch dir, not the repo):

```python
sys.path.insert(0, "<main>/backend")     # tools.* + the token cache beside them
sys.path.append("<worktree>/backend")    # portfolio.* from this branch
load_dotenv("<main>/backend/.env")

connector = IndMoneyConnector(transport=...)   # wraps tools.ind_money._call_mcp_tool
print(await connector.link_health("local"))
snapshot = await connector.fetch_snapshot("local")
for asset_type in (AssetType.MF, AssetType.IND_STOCK):
    await asyncio.sleep(4)
    rows = await connector.fetch_holdings("local", asset_type)
    # print len(rows), types, and booleans — nothing else
```

**Result on this branch (2026-08-15), against the operator's live account:**

| Check | Result |
| --- | --- |
| `link_health` | `linked` (token auto-refreshed, no re-auth needed) |
| `fetch_snapshot` | returned a `PortfolioSnapshot`; `net_worth` is a `Decimal` and > 0; gross / invested / liabilities all present |
| snapshot `currency` / `as_of` | `INR` / tz-aware UTC (stamped, since no payload carries a date) |
| snapshot breakdown rows | 4 asset-type, 3 asset-class, 13 sector, 4 market-cap |
| asset types seen | `MF`, `SA`, `US_STOCK`, `UNKNOWN` |
| raw asset-type strings | `MF`, `SA`, `US_STOCK`, **`US_STOCK_WALLET`** — the out-of-enum bucket mapped to `UNKNOWN` with its string intact, exactly as C2 predicted |
| US-exposure buckets | 2 |
| `fetch_holdings(MF)` | 9 rows, all typed `Holding`, all INR, all tz-aware, all values `Decimal`, 9 unique ids, 9 with a `pnl_pct`, 0 with an unknown cost basis |
| `fetch_holdings(IND_STOCK)` | 0 rows — the 19-key envelope parsed cleanly and the account still holds no Indian stocks |
| conformance | no exception, no shape error, no currency error |

Two things this did **not** verify, and cannot until the account changes: a
populated `IND_STOCK` row, and a real unknown-cost-basis row (this account is on
IND Money's own rails, so `invested_amount` was present on all 9 MF rows — the
0/`null`/absent paths are covered by fixtures only).

The raw payloads were written to a scratch directory outside the repo purely so
the leak gate in §3 could be run against this branch, and **deleted immediately
afterwards**.

## 5. Scope check

```bash
git diff main --name-only
```

Must list only `backend/portfolio/**`, `backend/tests/**` and `docs/**`. Any
hit under `backend/api/`, `backend/agents/`, `backend/graph/`, `backend/tools/`,
`backend/db/`, `Dockerfile` or `requirements*.txt` means the card exceeded its
scope.
