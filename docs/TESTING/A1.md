### Mutation checks (review round)

Each named guard fails when neutered, and reverts cleanly:

- **anti-fabrication detector** — reverting `invented_figures` to the substring
  trace fails the 4 substring-adjacent cases + the structural unit test (and a
  `return []` mutation fails all 6); the `42%` (fully-out-of-range) case still
  passes the old check, which is why it is kept separate.
- **`redact()` at the integration point** — deleting the call from `_catalog`
  **or** from `run_synthesizer` fails `test_every_prompt_is_routed_through_redact`.
- **stream tracing-off** — a plain config in `overview_stream` fails
  `test_overview_stream_also_carries_tracing_off`.
- **global spend cap** — removing the global check fails
  `test_global_daily_cap_denies_across_users`.

### The langsmith-cache fixture (why `conftest.py` changed)

`langsmith.utils.get_env_var` is `lru_cache`d, so the first read of the tracing
env vars freezes for the process. A1 is the first card to actually **run** a
LangGraph in the suite; the graph reads the tracing state (off), which would
otherwise freeze "disabled" and make `test_portfolio_config`'s control case fail
depending on file order. An autouse fixture in `conftest.py` clears that cache
around every test, restoring order-independence. Removing the fixture makes the
full-suite run order-dependent (three `test_portfolio_config` failures when a
graph test runs first) — a good mutation check.

## The one live call (happy path)

Gated on `RUN_OPENAI_LIVE=1` **and** `OPENAI_API_KEY` present, so ordinary CI
spends nothing. It makes **one** real call — a single specialist against real
OpenAI — proving connectivity, that `provider="openai"` reaches
`api.openai.com`, and that the model cites by `[[token]]`. The full multi-agent
graph is proved with mocked LLMs. Keep it to one call; do not run the whole graph
live.

```bash
# backend/.env supplies OPENAI_API_KEY (never printed/committed)
cd backend && RUN_OPENAI_LIVE=1 pytest tests/test_overview_live.py -q
```

Verified 2026-08-16: **1 passed** (one real call).
