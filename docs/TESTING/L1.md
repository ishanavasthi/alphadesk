# Testing L1 — the invite gate

## Run it

**Backend** (needs Postgres — the cascade and `timestamptz` behaviour are exactly
what SQLite would lie about; see `docs/TESTING/F1.md` for the one-line container):

```bash
docker run --rm -d --name alphadesk-pg \
  -e POSTGRES_PASSWORD=test -e POSTGRES_DB=alphadesk -p 5433:5432 postgres:16
cd backend
TEST_DATABASE_URL=postgresql+asyncpg://postgres:test@localhost:5433/alphadesk pytest -q
# 670 passed, 1 skipped (the gated live OpenAI test)
```

The L1 files specifically:

```bash
TEST_DATABASE_URL=... pytest -q \
  tests/test_account_deletion.py tests/test_ratelimit.py tests/test_admin_removed_l1.py
```

## What each suite covers

### `test_account_deletion.py` — the acceptance centerpiece

`test_delete_account_removes_every_row_and_revokes_upstream` seeds a user with a
row in **every** table (`users`, `broker_links`, `oauth_pending`, `snapshot_days`,
`snapshot_holdings`, `snapshot_raw`, `watchlist`) **and** in-memory Lab state, then:

- monkeypatches `tools.ind_money_auth.revoke_token` to a recorder;
- calls `DELETE /account` with a stub Clerk JWT (`tests/clerk_stub`);
- asserts the response is `deleted: true, revoked_upstream: true`;
- asserts revocation was called **with the decrypted refresh token** (order: upstream first);
- asserts a row-count of **0 in every table** (`ALL_MODELS` — add a table to the
  schema without adding it here and the exhaustiveness check still counts it,
  because the model list is the source of truth);
- asserts the in-memory Lab state for the user is gone.

`test_a_re_used_id_gets_a_fresh_row_after_deletion` pins the seen-user eviction: a
later authenticated call recreates the `users` row (else the FK backstop would
fire on the user's next write). `test_delete_account_requires_a_token` pins JWT-only.

Note: `tests/conftest.py` `_ALL_TABLES` now includes `watchlist` — it was missing,
so watchlist rows had been surviving the between-test truncation.

### `test_ratelimit.py`

Per-caller 429 (repeated calls under one token), global 429 (distinct tokens, so
only the global cap can stop them), unguarded paths untouched, the disable switch,
and the guarded-path set. Every request is stopped at the middleware before auth,
so no DB or token is needed.

### `test_admin_removed_l1.py` — the F3 §5 checklist (structural)

One assertion per removed backend symbol (sites 1–6): the functions are gone and
the identity dependencies no longer take an `x_alphadesk_admin_secret` parameter.
Plus a grep that no shipped Python still reads `ALPHADESK_ADMIN_SECRET`. The
**behavioural** half — an admin header authenticates nothing — lives in
`test_api_auth_f3.py::test_no_admin_path_authenticates_post_l1` and
`test_api_portfolio.py::test_admin_header_no_longer_authenticates`, both of which
keep `ALPHADESK_ADMIN_SECRET` **set** so they prove the header is inert because the
code is gone, not because the secret is unconfigured.

### Frontend

- `consent.test.tsx` — clicking Connect opens consent and does **not** start OAuth;
  only agreeing calls `startAuthLogin`; cancel starts nothing; the dialog names
  every read/never line; and a source scan pins that all three Connect entry
  points import `useLinkConsent`.
- `delete-my-data.test.tsx` — the delete button arms only on the typed word,
  the wrong word does nothing, confirm calls `deleteAccount` then `signOut`.
- `policy-pages.test.tsx` — the privacy page names all six subprocessors (both LLM
  providers included) and the retention/deletion facts; terms states no-orders +
  not-advice; the footer links `/privacy` + `/terms`.
- `auth-boundaries.test.ts` / `auth-credentials.test.ts` — updated to the post-L1
  posture: `lib/api.ts` no longer contains the admin header or its env var, and no
  endpoint sends one.

## Verify by hand

1. **Delete-my-data end to end** (needs the operator wiring — Neon + Clerk):
   sign in, link IND Money, capture a snapshot, add a watchlist item. Open the
   account menu → **Delete my data** → type `DELETE` → confirm. You are signed out
   and returned to `/`. In Neon, `SELECT count(*) FROM users WHERE id = '<your id>'`
   and each dependent table return 0. IND Money shows the grant revoked.
2. **Consent is unskippable:** on `/portfolio` (unlinked) or the Lab, click
   Connect — the consent screen appears first; Cancel returns you without any
   `/auth/login` request (check the network tab); Agree opens the broker popup.
3. **Policies:** `/privacy` and `/terms` render the real content; the footer link
   is present on `/`, `/demo`, `/portfolio`, and `/lab`.
4. **Rate limit:** set `RATE_LIMIT_PER_CALLER_MAX=2` on the backend and hit
   `POST /auth/login` three times quickly — the third is a 429 with `Retry-After`.
5. **No admin path:** with `ALPHADESK_ADMIN_SECRET` set on the backend, a
   `GET /portfolio/summary` carrying only `x-alphadesk-admin-secret` returns 401.
